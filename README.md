# 🌌 Portfolio Cá Nhân — Dino Péo

Dự án Portfolio cá nhân hiệu năng cao, nơi trưng bày các kỹ năng kỹ thuật và các sản phẩm sáng tạo.

---

## ⚡ Các Tính Năng Chính

- **Phần Hero:** Giới thiệu với hiệu ứng gõ chữ (typing) các vai trò linh hoạt.
- **Về Tôi:** Kinh nghiệm chuyên môn và sở thích cá nhân.
- **Công Nghệ:** Hiển thị tương tác các công nghệ và kỹ năng sử dụng.
- **Dự Án:** Trưng bày các dự án nổi bật và các sản phẩm đáng chú ý khác.
- **Liên Hệ:** Biểu mẫu liên hệ hoạt động thực tế và tương tác email trực tiếp.
- **Đa Ngôn Ngữ:** Hỗ trợ đầy đủ Tiếng Anh và Tiếng Việt.
- **Chế Độ Giao Diện:** Chuyển đổi linh hoạt giữa chế độ Sáng và Tối.

---

## 🛠️ Công Nghệ Cốt Lõi

- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Framer Motion**

---

## ⚙️ Cách Khởi Chạy

1. `npm install`
2. `npm run dev`
