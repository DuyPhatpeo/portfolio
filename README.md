# 🌌 Portfolio Cá Nhân — Dino Péo

**Portfolio – Trang giới thiệu cá nhân**

## 📖 Mô Tả Dự Án

Đây là dự án website portfolio cá nhân được xây dựng với hiệu năng cao, nhằm mục đích giới thiệu bản thân một cách chuyên nghiệp. Trang web cung cấp cái nhìn tổng quan và chi tiết về các kỹ năng, ngôn ngữ lập trình tôi đang sử dụng. Đồng thời, đây cũng là nơi trưng bày những dự án nổi bật đã thực hiện, giúp hệ thống hóa toàn bộ kinh nghiệm làm việc. Ngoài ra, website còn cung cấp thông tin liên lạc đầy đủ và tích hợp sẵn biểu mẫu gửi tin nhắn trực tiếp, giúp người xem dễ dàng kết nối và trao đổi công việc.

---

## ⚡ Các Tính Năng Chính

- **Phần Hero:** Giới thiệu với hiệu ứng gõ chữ (typing) các vai trò linh hoạt.
- **Về Tôi:** Kinh nghiệm chuyên môn và sở thích cá nhân.
- **Công Nghệ:** Hiển thị tương tác các công nghệ và kỹ năng sử dụng.
- **Dự Án:** Trưng bày các dự án nổi bật và các sản phẩm đáng chú ý khác.
- **Liên Hệ:** Biểu mẫu liên hệ hoạt động thực tế (tích hợp EmailJS) và tương tác email trực tiếp.
- **Đa Ngôn Ngữ:** Hỗ trợ đầy đủ Tiếng Anh và Tiếng Việt (i18next).
- **Chế Độ Giao Diện:** Chuyển đổi linh hoạt giữa chế độ Sáng và Tối.
- **Hiệu Ứng Mượt Mà:** Sử dụng Framer Motion cho các hoạt ảnh và chuyển đổi mượt mà.

---

## 🛠️ Công Nghệ Cốt Lõi

- **Framework & Thư Viện:** React 19, TypeScript, Vite
- **UI & Styling:** Tailwind CSS 4, Framer Motion, Lucide React, React Icons
- **Quản Lý Trạng Thái:** Zustand
- **Đa Ngôn Ngữ:** i18next, react-i18next
- **Dịch Vụ Liên Hệ:** EmailJS (@emailjs/browser)
- **Định Tuyến & Khác:** React Router DOM, React Toastify

---

## ⚙️ Hướng Dẫn Cài Đặt & Khởi Chạy

1. **Clone dự án:**
   ```bash
   git clone https://github.com/DuyPhatpeo/portfolio.git
   cd portfolio
   ```

2. **Cài đặt thư viện:**
   ```bash
   npm install
   ```

3. **Thiết lập biến môi trường:**
   Tạo file `.env` (dựa trên các biến cần thiết từ EmailJS) ở thư mục gốc.

4. **Chạy môi trường phát triển (Dev):**
   ```bash
   npm run dev
   ```

5. **Xây dựng bản Production:**
   ```bash
   npm run build
   ```
